# Manager & Career-Clarity Kit

A small HR-analytics kit that shows where teams lose people and whether the cause looks like manager quality, a stalled promotion path, or both.

> **The demo data in this repo is synthetic.** It is generated by `build.py` and contains no real employee information.

## Try it on your own data (no coding)
1. Open `index.html` in any browser.
2. Drag a CSV onto the "Try it on your own data" box, or click **Choose file**.
3. The dashboard redraws from your file. **The file is read inside your browser. Nothing is uploaded, sent or stored anywhere.**

Click **Download CSV template** on the page to see the expected layout.

### Columns
| Column | Required | Notes |
|---|---|---|
| `manager_id` | Yes | Use codes, not names |
| `left_within_12m` | Yes | 1/0 or yes/no |
| `months_since_promotion` | Yes | Number |
| `function` | No | Enables function filters and the by-function chart |
| `engagement_score` | No | 1-5 from a survey. Without it, teams are ranked by exit rate instead |
| `employee_id`, `tenure_months` | No | Ignored by the page, fine to include |

Headers don't have to match exactly. The page guesses common names (for example "Department", "Attrition", "Reporting Manager") and shows a column-mapping box so you can correct it.

### Privacy tips
- Replace names with codes before loading.
- Teams of fewer than 5 people are hidden at manager level.
- To keep a real export out of version control, save it as `data/real/anything.csv`; `.gitignore` excludes that folder.

## What's inside
| File | Purpose |
|---|---|
| `index.html` | Interactive dashboard (single file, open in any browser) |
| `template.html` | Dashboard source, used by `build.py` |
| `build.py` | Generates the synthetic data and builds `index.html` |
| `data/employees.csv` | Synthetic demo data (440 rows, 60 managers) |
| `career_ladder.md` | Career-ladder template per function |
| `pulse_survey.md` | 8-question manager pulse with scoring |
| `memo.md` | Two-page proposal |

## Rebuild from source (optional)
```bash
python build.py                          # synthetic demo
python build.py --csv path/to/export.csv # embed your own data as the default view
```

## Limits
- Shows associations, not proof of cause. Confirm with conversations before acting.
- The value estimator uses adjustable assumptions, not real cost figures.
- The charts load Chart.js from a public CDN, so the page needs an internet connection.

## Intended use
A coaching tool to decide where to look and support first, not a ranking to punish managers.
